PART IV · SYNTHESIS
The scanner effect is not a detachable style layer
A universal image normalizer must solve calibration, information recovery, and physical compatibility at the same time.
Revising the hypothesis
Revised view

Shared biology does not imply scanner-independent pixels

Initial factorization

Is = Rs(B)

A canonical biology image plus detachable scanner style.

Evidence-supported view

z = EPFM(L, H, L×H, scanner optics)

Color is calibratable; focus/MTF are information-losing; UNI responds nonlinearly to LF–HF context.

Morphology is shared biology, but its pixel realization is not scanner-independent.
Conceptual update
The standard-image dilemma

Every target makes a different compromise

Blurry common denominator

All scanners can reach it, but content and representation collapse.

Sharp canonical target

Preserves detail, but blurrier scanners must invent missing morphology.

Preserve source HF

Keeps observed morphology—and the source scanner's focus/MTF signature.

Synthesize target HF

Risks hallucination, LF–HF incompatibility, and out-of-gamut composites.

The data do not prove impossibility. They expose the constraints a common image must satisfy.
No universal no-go claim
Current limits

What this pilot does—and does not—establish

Established mechanistically

  • LF appearance is strongly calibratable
  • LF alignment does not guarantee UNI alignment
  • Blur can fake convergence through collapse
  • HF response depends on LF reference
  • Some LF–HF combinations violate RGB range

Not yet established

  • Generalization across multiple PFMs
  • Population effect sizes beyond two test slides
  • Nucleus-level biological fidelity
  • Deployment value of the registered HF oracle
  • Mathematical impossibility of a common image

HF trajectories use three artifact-screened registered locations; UMAP is qualitative.
