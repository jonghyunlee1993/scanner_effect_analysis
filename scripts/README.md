# Upstream pipeline wrappers

SLURM wrappers and helper programs that produced the frozen upstream results in
`outputs/` and `data/`, which the manuscript analyses in `analysis/paper/` and
`analysis/revision/` read. Run commands from the repository root with the `cpath`
environment; the Python programs they call are in `src/`.

| Directory | Produces |
| --- | --- |
| `preprocessing/` | matched patches (`data/preprocessing_patch_extraction_matching_and_QC/`), the scanner cohort and locked locations, raw PFM embeddings (`outputs/scanner_batch_effect_analysis_2026-09-17/00_contract`, `03_uni`) |
| `augmentation/` | augmentation candidates and folds (`outputs/augmentation_ood_v1/`), image phenotypes and frequency spectra (`outputs/final_image_study_v1/`) |
| `translation/` | Pix2Pix, CycleGAN and stain-normalization baselines (`06_learned_baselines/`, `12_manuscript_completion/02_baseline_benchmark/`) |
| `plism/` | PLISM rendering and external evaluation (`outputs/plism_factorial_external_v1/`, `12_manuscript_completion/05_plism_external_correction/`) |
| `features/` | ridge, ComBat and cross-PFM feature correction (`outputs/feature_crossencoder_review_2026-09-25/`, `outputs/gan_encoder_review_2026-09-25/`) |
| `frequency/` | frequency-correction mechanism results (`12_manuscript_completion/04_frequency_mechanism/`) and the band-manipulation code reused by RV02; the cross-PFM color--frequency summary used by Fig. 4 was produced by `run.py` and `aggregate.py` inside `outputs/table4_color_frequency_crossencoder_2026-09-25/` |

The 22 root-level `manuscript_completion_*.sbatch` files are symbolic links to the
categorized wrappers. They are kept because the frozen execution contracts in
`src/manuscript_completion/` check the scripts by these paths. The former path map is
in `docs/records/restore_maps/scripts_entrypoints.tsv`.

The UNI ridge and ComBat results were generated by
`features/feature_uni_v1_internal.sbatch` followed by
`features/feature_uni_v1_external.sbatch` (submit the external job with an `afterok`
dependency on the internal job). Frozen inputs for
`features/review_feature_crossencoder_aggregate.py` are in
`outputs/discussion_followup_2026-09-25/`.
